# Permissions

Generated by `stuffcloud-app permissions` from the permission matrix
(`crates/core/src/policy.rs`) and the route table (`crates/app/src/server.rs`); a test
fails when this file is stale. SPEC 6 and 10.4 explain the rules.

## Matrix

of the same area. A service account has tokens only, never a session.

Deploy with the CLI

Publish a folder from your terminal or from CI. The CLI needs an API token with the sites:write scope.

Install

npm install --global stuffcloud

Deploy

# publish ./dist for 7 days
stuffcloud deploy ./dist --expires 7d

# protect it with a password
stuffcloud deploy ./dist --password
Anonymous deploys reach internal zones only. Public zones and permanent sites need an account.

Use it in CI

env:
  STUFFCLOUD_TOKEN: (from your CI secret store)
